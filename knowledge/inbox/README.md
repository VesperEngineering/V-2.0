# Knowledge inbox

Draft memories and procedures belong here while they are being reviewed. The
runtime never admits this directory as active knowledge. `knowledge-observe`
creates or updates candidates here after an explicit request or three distinct
observations of the same concept key.

Review candidates in Obsidian or another Markdown editor. An operator manually
sets `vesper_status: approved` and moves an approved note to `memory/` or
`skills/`; the controller never approves or moves files. To archive an adaptive
note, an operator manually moves it to the matching `archive/` directory and
sets `vesper_status: archived`.

Do not place secrets, credentials, raw market data, task progress, or temporary
session notes in the vault.
