# V20 startup checklist

## When to use
At the start of every task or session involving code changes, configuration, or repository work.

## Procedure

1. **Read `AGENTS.md`** – Confirm scope, rules, and authority limits for this workspace.
2. **Check git status** – Identify dirty files, uncommitted changes, or unrelated modifications.
3. **Verify tool availability** – Ensure required tools (read/write/test/graph) are accessible.
4. **State assumptions** – Document any gaps before proceeding.

## Enforcement
- This checklist is mandatory before any code/config modification in V20.
- Skipped steps invalidate the task handoff and require rework.
