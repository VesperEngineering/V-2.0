# Vesper Engineering: reference-synthesis example

This is a worked example of turning mixed references and repeated user corrections into a precise identity brief. It is not a reusable logo specification and should not be copied literally for unrelated brands.

## Inputs

- Quant-firm collage: institutional credibility and compact emblems. The user ultimately identified **Jane Street** as the strongest draw because its mark is odd, abstract, and simple.
- The Branx portfolio: identities feel unique through one decisive visual move, not added complexity.
- Vercel: pure-black primitive geometry, severe reduction, generous negative space, and confidence at tiny sizes. Transfer the simplicity—not the triangle.

## Corrections that materially changed the brief

- Exact name: **Vesper Engineering**.
- The emblem sits above the wording.
- **VESPER ENGINEERING must remain on one horizontal line**, not a stacked name/subtitle lockup.
- Typography should be restrained and thinner than the initial drafts, but not so fragile that it fails on apparel.
- Multiple examples are welcome only when they represent genuinely different visual families.
- The user rejected marks built from convergence, orbits, residual lines, outliers, folded ribbons, hidden paths, accent dots, and similar post-rationalized “quant” metaphors.
- The attraction is not primarily a semantic story. It is the immediate visual quality of an **odd, abstract, simple black emblem**.

## Final direction

Combine:

1. Jane Street’s permission for an emblem to be unusual and abstract.
2. Vercel’s ruthless one-color simplicity and memorable silhouette.
3. The quiet credibility expected of an established quantitative firm.

Hard constraints:

- standalone emblem above;
- `VESPER ENGINEERING` on one line below;
- begin in pure black and white;
- one compact silhouette or very few shapes;
- no forced V monogram;
- no chart, candlestick, arrow, node network, orbit, signal line, or data-point metaphor;
- no decorative dot, slit, gradient, glow, or accent unless later requested;
- recognizable at favicon size and reproducible on a shirt.

## Working method

1. Ask what quality of each reference attracts the user; do not infer it solely from brand category.
2. Distinguish semantic concept from visual character. Here, visual character won.
3. Draft silhouettes in monochrome before adding rationales or color.
4. If full-logo rounds keep missing, switch to numbered 5×5 monochrome symbol sheets. Build a broad field before asking for a shortlist; this session used 100 symbols across four boards.
5. After shortlisting, isolate each chosen glyph and place every finalist into the same wordmark lockup for a fair comparison. The shortlist here was symbols 22, 46, and the bent-operator mark.
6. The later preference became wordmark-led: `VESPER ENGINEERING` carries the authority while a smaller, nimble symbol behaves like notation or a signature.
7. Evaluate spelling, one-line lockup, small-size silhouette, and accidental resemblance to known marks.
8. Treat generated raster art as exploration; rebuild the selected mark as clean vector geometry.

## Image-backend lesson

When the managed FAL model returned HTTP 402 repeatedly, retrying the same backend was not useful. Hermes already had OpenAI Codex OAuth. Switching the image backend to `openai-codex` with gateway disabled allowed `gpt-image-2-medium` generation without an OpenAI API key. Capture the recovery pattern, not the transient outage: inspect provider configuration, use an already-authenticated alternative, then verify with a real generation.

## General lesson

Do not confuse “minimal” with “a sparse shape plus a clever explanation.” Some users want a mark that feels compelling before it is explained. When repeated concepts are rejected, remove devices and metaphors rather than inventing new ones. Odd silhouette + severe reduction can itself be the design thesis.
